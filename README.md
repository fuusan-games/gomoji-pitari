# ごもじでピタリ 〜ふーさんの いいかえクイズ〜

お題を **漢字2文字＋カタカナ3文字** の「5文字」で言いかえて、親に当ててもらうブラウザ用パーティーゲームです（3〜6人、空いた席は ふーさん🐻）。
ひとり1台のスマホ（iPhone Safari / Android）や PC で遊びます。P2P（PeerJS）でホストの端末が進行役になり、サーバーは使いません。

> 市販のボードゲーム「ゴモジン」（JELLY JELLY GAMES／作：郡山喜彦）の **ルールの仕組み** を参考にした、非公式のファンメイド作品です。
> 名前・見た目・UI文・お題リスト（約340題）・ふーさんの5文字はすべてオリジナルで、製品のカード内容・説明書の文章・アートは使っていません。

## 遊び方（このアプリのルール）

1. 人数と同じ回数だけ親を交代（時計回り）。親は「当てる人」、ほかの全員が「書く人」。
2. 親が **カタカナ** か **漢字** のカードを選ぶ → 親の次の席の人が 🎲 をふる → 出た目（1〜6）のお題に決定。
   親の画面には答え合わせまで お題が出ません（親の端末にはお題データ自体を送りません）。
3. 書く人は **60秒**（ロビーで90秒も選べる）で、お題を漢字2＋カタカナ3で言いかえる。
   - お題に含まれる **漢字** と、お題の読みの **連続するカタカナ3文字** は使えない（入力中に自動チェック）。
   - 「ー」や小さい字（ャュョッ など）も1文字。カタカナは外来語でなくてもOK（ハシル・クルマ など）。
4. 書けたら **番号タイル** を早い者勝ちで取る＝提出。全員出すか時間切れでおしまい。間に合わなかった人は発表なし。
5. 番号の小さい順に1つずつ見せ、親はそのたびに1回答える（パス可）。正解でおしまい、はずれなら次へ。全部はずれなら得点なし。
6. 得点：親は1つ目で正解 **30**／2つ目 **20**／3つ目以降 **10**。当てられた5文字を書いた人は **10**＋漢字が二字熟語なら **+10**＋カタカナがカタカナ言葉なら **+10**。
7. 反則の5文字がめくられたら、親以外の人が 🚩 で指摘 → そのお題は終わり（得点なし）、同じ親でお題を決め直し。
8. 全員が1回ずつ親をしたら終了。合計点の高い順（同点は同順位）。

## 確認できなかった点（このアプリでの仮定）

- 5文字の並びは **漢字2→カタカナ3の順で固定**（どの例もこの順で、試作名も「□□○○○」）。
- 「々」は2文字目なら可（前の漢字と同じ字として禁止チェック）。先頭は不可。
- 濁点・半濁点・小さい字のちがいは **別の文字**（完全一致だけ自動で禁止。にているものは ⚠注意 を出し、判断はみんなに任せる）。
- 同音異字（帽子↔消防士 など）・意味がそのままの直訳は自動では止めない → 🚩反則 で指摘できる（だれかが1人で指摘できる仕組み）。
- 親が答えられるのは めくった1枚につき1回（パスも1回とみなす）。親が答える時間に制限はなし。
- 親の点は「何枚目に公開されたか」で決める（番号の数字そのものではない）。
- 番号タイルは書く人の数だけ（最大5）。最初の親はランダム。同点は同順位（タイブレークなし）。
- 二字熟語／カタカナ言葉のボーナスは、辞書（お題データ由来の目安）で自動判定し、ホストがタップで切りかえ。
- 自動判定で×でも、親以外の人間が「⭕正解にする」で正解あつかいにできる（表記ゆれ対策）。
- 切断中の人の番は、少し待ってから ふーさん🐻 が代わりに動く。

## ふーさん🐻（CPU）

強さは 🐢ゆっくり／🐻ふつう／⚡はやい（ロビーで1人ずつ／まとめて変更）。

- **書く人のとき**：お題ごとに用意したオリジナルの5文字（約1,000個、各お題2〜4個）から選びます。全部がルールどおりかを `test/logic.test.js` で毎回検証。
  ほかの ふーさんと同じ5文字は避けます。書き上がる時間は 🐢24〜52秒／🐻12〜38秒／⚡6〜20秒（60秒設定時）、まれに「思いつかない」ことも（🐢12%・🐻4%）。
  自信があるとき（いちばん良い5文字）は小さい番号を、そうでないときは少しあとの番号を取ります。
- **当てる人（親）のとき**：見えている5文字だけを使います（お題も模範の5文字も見ません）。
  候補＝その種類（カタカナ／漢字）の全お題＋まぎらわしい「おとり」約80語。各候補の「連想ことば」と5文字の漢字・熟語・カタカナの重なりを、珍しい言葉ほど重く（IDF）点数化。
  5文字に候補の漢字や読みの3文字が入っていれば「ルール上ありえない」ので除外。前に答えて外れた語も除外。
  強さごとに「知っている連想の割合」（🐢55%・🐻72%・⚡86%）と迷い（ランダムなゆらぎ）が変わるので、まちがえることもあります。
  模範の5文字での目安：1つ目で正解 🐢約47%・🐻約69%・⚡約74%、3つまでに 90〜99%。
- 「〜クマ」の吹き出しでしゃべります（書けた・1番取った・答え・正解/はずれ など）。

## 画面・操作の工夫

- 5文字入力は「漢字2文字」「カタカナ3文字（ひらがなでOK）」の2つの欄。ひらがなは変換確定後に自動でカタカナに。半角カナも全角に。
  入力中に □□○○○ のプレビューと ✕/⚠ のチェック結果を表示し、反則の5文字は提出できません。
- 入力欄のDOMは受信のたびに作り直さないので、変換（IME）が途中で切れません（compositionstart/end を考慮）。
- iPhone でキーボードが出たら visualViewport に合わせて画面を縮め、入力欄と番号タイル／答えるボタンがキーボードに隠れないようにします。ページ全体はスクロールしません。
- 残り10秒からカチカチ音（残り5秒からは高い音）、タイムアップ音、サイコロ・めくり・正解/はずれ・得点ポップ・紙ふぶき。BGM・効果音は Web Audio で合成（外部音源なし）。
- ⋯メニュー：中断してロビーに戻る（ホスト）／ロビーに戻りたい（参加者）／音／あそびかた／退出／ひろばへ。
- `?from=portal` またはホーム画面アプリ（standalone）のときだけ「🏠 ひろばへ」ボタンを表示（ゲーム中は非表示）。
